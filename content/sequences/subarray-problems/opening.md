A subarray is a run of items that sit next to each other in an array. Many questions about data in a row are questions about such runs. Given the daily changes of a price, the best single purchase and later sale is the run of days with the largest sum. Given a score for each base of a DNA sequence, a region rich in G and C is a run with a high average. Given the heights of the bars of a histogram, the largest rectangle under it covers a run of bars. An array of $n$ items has $n(n+1)/2$ non-empty subarrays, so trying them all costs at least quadratic time, and summing each one from scratch costs cubic time. The point of this chapter is that a few ideas cut nearly every such problem down to one linear pass.

There are four such ideas. A *scan* keeps the best answer for runs that end at the current item, as [Kadane's algorithm](/kadane-algorithm/) does. A *window* keeps two pointers that only move right, when the condition on a run is monotone. *Prefix sums* turn a run into a pair of points, so that a question about runs becomes a question about pairs of numbers, which a hash table, a deque or a trie can answer. A *monotonic stack* finds, for each item, how far it reaches on both sides before a smaller item stops it.

## What the chapter covers

The chapter is in seven groups, read in order.

1. **The maximum subarray.** The [subarray](/subarray/) itself and the [maximum subarray problem](/maximum-subarray-problem/), with [Kadane's algorithm](/kadane-algorithm/) in $\Theta(n)$ time and the [divide-and-conquer algorithm](/maximum-subarray-divide-and-conquer/) in $\Theta(n \log n)$ time.
2. **Variations on Kadane's scan.** The [circular](/circular-kadane-algorithm/) form, the [largest product](/kadane-max-product/), which must also track the smallest product, and the best $k$ disjoint runs in the [k-maximum subarray problem](/k-maximum-subarray-problem/).
3. **Two dimensions.** The [maximum sum submatrix](/maximum-sum-submatrix/) and the [Bentley column sweep](/bentley-column-sweep/), which solves it in $\Theta(m^2 n)$ time.
4. **Sliding windows.** The best window of a [fixed length](/maximum-sum-subarray-of-fixed-length/), the shortest window with a large enough sum when items are [positive](/sliding-window-positive-sum/), and the longest window with at most $k$ [distinct values](/distinct-count-two-pointers/).
5. **Prefix sums with a hash table.** Counting the runs with a given sum in [subarray sum equals k](/subarray-sum-equals-k/), by [prefix sum hash counting](/prefix-sum-hash-counting/), the [longest zero-sum subarray](/longest-zero-sum-subarray/), and the [maximum XOR subarray](/maximum-xor-subarray/) with a binary trie.
6. **Negative items and length conditions.** The [shortest subarray with sum at least K](/shortest-subarray-sum-at-least-k/) and the [monotonic deque over prefix sums](/monotonic-deque-prefix-sums/) that solves it, then the [maximum density segment](/maximum-density-segment/).
7. **Rectangles under a histogram.** The [largest rectangle in a histogram](/largest-rectangle-in-histogram/), the [histogram stack algorithm](/histogram-stack-algorithm/), and the [maximal rectangle in a binary matrix](/maximal-rectangle-binary-matrix/).
