1. ◦ A hospital must keep its records secret for $x = 20$ years, its move to post-quantum key exchange will take $y = 6$ years, and it plans for a quantum computer in $z = 15$ years. Use Mosca's inequality from [harvest now, decrypt later](/harvest-now-decrypt-later/) to say whether the hospital is late, by how many years, and which years of recorded traffic, counted from now, an attacker will be able to read. Do the same for a shop with $x = 8$, $y = 4$ and $z = 15$.

2. ◦ A parameter set's best classical attack costs $2^{150}$ gates, and its best quantum attack costs $2^{125}$ quantum gates at any circuit depth. Using the 2022 figures in [NIST security levels](/nist-security-levels/), which of categories 1, 2 and 3 does it meet when MAXDEPTH is $2^{40}$? When MAXDEPTH is $2^{96}$?

3. ◦ In the hybrid X25519MLKEM768 key exchange, the client sends an ML-KEM-768 encapsulation key and an X25519 share, and the server answers with an ML-KEM-768 ciphertext and an X25519 share. Using the sizes in [ML-KEM](/crystals-kyber/) and 32-byte X25519 shares, compute the size of both messages, and check them against [post-quantum cryptography](/post-quantum-cryptography/). How large would the two messages be if ML-KEM-1024 took the place of ML-KEM-768?

4. ◦ A [McEliece](/mceliece-cryptosystem/) key uses a binary Goppa code with $n = 4608$, $m = 13$ and $t = 96$, so the code has dimension $k = n - mt$. The public key is the non-identity part of a systematic matrix, $k(n - k)$ bits, and the ciphertext is a syndrome of $n - k$ bits. Compute both sizes in bytes, and the ratio of the public key to the 800-byte encapsulation key of ML-KEM-512.

5. ◦ In [ML-KEM](/crystals-kyber/), $q = 3329$, $\text{Compress}_d(x) = \lceil (2^d/q)\, x \rfloor \bmod 2^d$ and $\text{Decompress}_d(y) = \lceil (q/2^d)\, y \rfloor$. Compress $x = 2000$ with $d = 4$ and $x = 3000$ with $d = 10$, decompress the results, and say how far each is from $x$. Then compress $x = 3328$ with $d = 4$ and explain why the answer is still close to $x$.

6. ◦ In $\mathbb{Z}_{17}[x]/(x^4 + 1)$, multiply $a = 1 + 2x + x^3$ by $b = 3 + x^2$. Then compute the same product in $\mathbb{Z}_{17}[x]/(x^4 - 1)$. Which coefficient differs, and why?

7. ◦ Let $H$ be the $3 \times 7$ parity-check matrix of the Hamming code whose column $j$ is $j$ in binary, top bit first. In a toy [Niederreiter](/niederreiter-cryptosystem/) scheme the ciphertext is the syndrome $s = He$ of a weight-1 error $e$. Decrypt $s = (1, 0, 1)^\mathsf{T}$. Then compute the syndrome of the weight-2 error with ones at positions 2 and 7, and say why this code cannot carry weight-2 messages. (The code is public and tiny; the scheme is insecure.)

8. ◦ For a prime $p \equiv 11 \pmod{12}$ there are exactly $\lfloor p/12 \rfloor + 2$ supersingular $j$-invariants. Check that $p = 419$ satisfies the condition and count them. How many vertices does the 2-isogeny graph of [the supersingular isogeny problem](/supersingular-isogeny-problem/) have for this $p$, and how many 2-isogenies leave each vertex? How many 3-isogenies?

9. • Run [Regev encryption](/regev-encryption/) with $q = 101$, $n = 2$, the secret $s = (30, 7)$, the rows $a_1 = (23, 57)$, $a_2 = (8, 90)$, $a_3 = (64, 15)$, $a_4 = (41, 77)$ and the errors $e = (1, 0, -1, 1)$. Compute the public vector $b$. Encrypt the bit 1 with the subset $\{1, 2, 4\}$ and decrypt it. If every error lies in $\{-1, 0, 1\}$ and the subset may be any subset of the $m$ samples, what is the largest $m$ for which decryption can never fail?

10. • [Saber](/saber/) rounds from $q = 2^{13}$ to $p = 2^{10}$ with $x \mapsto \lfloor (p/q)\, x \rceil$, rounding halves up. Round $x = 5000$, $5003$ and $5004$, multiply each result by $q/p$, and give the hidden error $x - (q/p)\lfloor (p/q)x \rceil$. Prove that the hidden error never exceeds $q/(2p)$ in absolute value, as [learning with rounding](/learning-with-rounding/) states, and give that bound for Saber.

11. • Factor $q - 1$ for $q = 3329$ (ML-KEM), $q = 8380417$ (ML-DSA) and $q = 12289$ (Falcon). For which of the three does $x^{256} + 1$ split into linear factors mod $q$? Show that mod 3329 it splits into 128 quadratic factors, and say why the [number-theoretic transform](/number-theoretic-transform/) of ML-KEM has 7 layers. Does $x^{1024} + 1$ split into linear factors mod 12289?

12. • Let $A$ be a uniform $64 \times m$ matrix mod $q = 257$ and $f_A(x) = Ax \bmod q$ on $x \in \{0, 1\}^m$. Find the smallest $m$ for which $f_A$ must have a collision, and show that a collision gives a [short integer solution](/short-integer-solution/) with entries in $\{-1, 0, 1\}$. Why does the existence of collisions not make SIS easy?

13. • A random binary $[40, 20]$ code hides an error of weight $w = 4$. Using the round counts of [Prange's algorithm](/prange-algorithm/) and of the [Lee-Brickell algorithm](/lee-brickell-algorithm/), compute the expected number of rounds of Prange and of Lee-Brickell with $p = 1$ and $p = 2$.

14. • A toy [oil and vinegar](/unbalanced-oil-and-vinegar/) central map over $\mathbb{F}_7$ has oil variables $o_1, o_2$, vinegar variables $v_1, \ldots, v_4$ and the two polynomials $f_1 = o_1 v_1 + 2 o_1 v_3 + o_2 v_2 + 3 o_2 v_4 + 3 v_1 v_4 + v_2^2$ and $f_2 = o_1 v_2 + o_2 v_1 + 4 o_2 v_4 + v_3 v_4 + 5$. Fix $(v_1, v_2, v_3, v_4) = (1, 0, 2, 3)$ and find the oil values with $(f_1, f_2) = (4, 1)$. Why does the map have no term $o_1 o_2$ or $o_i^2$, and what does the signer do when the linear system is singular?

15. • The [Arora-Ge algorithm](/arora-ge-algorithm/) treats every monomial of degree 1 to $D = |E|$ in the secret as an unknown. Count the unknowns for $n = 10$ with errors in $\{-1, 0, 1\}$, for $n = 10$ with errors in $\{-2, \ldots, 2\}$, and for $n = 256$ with errors in $\{-1, 0, 1\}$. What does this say about schemes with very small errors and about the number of samples they may publish?

16. • Under the [core-SVP](/core-svp-hardness/) model, which BKZ block size $b$ first gives 128 bits of classical security, and which gives 128 bits of quantum security? For Kyber512, with $b = 403$, compute both estimates. Kyber512 still claims category 1; explain why the two numbers are not in conflict.

17. • A proof in the [quantum random oracle model](/quantum-random-oracle-model/) loses $2q\sqrt{\varepsilon}$ by the one-way to hiding lemma, where $q$ is the number of oracle queries and $\varepsilon$ the probability of the bad event. For $q = 2^{60}$, how small must $\varepsilon$ be for the loss to be at most $2^{-64}$? What loss does $\varepsilon = 2^{-128}$ give?

18. • Hash-based signatures are the fifth post-quantum family. For a 192-bit digest and 24-byte hash values, as in SLH-DSA-192, compute the sizes of a [Lamport](/lamport-signature/) public key and signature. Then compute the number of chains $\ell$ and the signature size of [Winternitz](/winternitz-one-time-signature/) with $w = 16$ and with $w = 256$.

19. • An LPN instance has noise rate $\tau = 1/8$. What is the bias $\delta$ of the error? [BKW](/bkw-algorithm/) with $a$ blocks leaves samples whose error has bias $\delta^{2^{a-1}}$, and it needs a number of votes that grows like $\delta^{-2^a}$. Compute both quantities for $a = 3$ and $a = 5$.

20. ★ An [ML-DSA](/crystals-dilithium/) signing attempt is kept only if every coefficient of $z = y + c s_1$ ($\ell$ polynomials) is below $\gamma_1 - \beta$ in absolute value and every coefficient of the low part of $w - c s_2$ ($k$ polynomials) is below $\gamma_2 - \beta$. Model the coefficients of $y$ as uniform in $(-\gamma_1, \gamma_1]$ and the low parts as uniform in $(-\gamma_2, \gamma_2]$, all independent, with $n = 256$. Show that one attempt succeeds with probability about $\exp(-256\beta(\ell/\gamma_1 + k/\gamma_2))$, and compute the expected number of attempts for the three parameter sets of the entry. Compare with the figures of FIPS 204.

21. ★ Suppose [Ring-LWE](/ring-learning-with-errors/) were set in $\mathbb{Z}_q[x]/(x^n - 1)$ instead of $\mathbb{Z}_q[x]/(x^n + 1)$, with $n = 8$, $q = 97$ and error coefficients in $\{-1, 0, 1\}$. Show that $p(x) \mapsto p(1) \bmod q$ is a ring homomorphism to $\mathbb{Z}_q$, and use it to tell Ring-LWE samples $(a, as + e)$ from uniform pairs. With 5 samples, bound the probability that uniform pairs pass your test. Why does the same idea fail for $x^n + 1$?

22. ★ Show that an algorithm for decision [LWE](/learning-with-errors/) with prime modulus $q$ gives an algorithm for search LWE. Guess $s_1 = g$, map each sample $(a, b)$ to $(a + r e_1, b + r g)$ with a fresh uniform $r \in \mathbb{Z}_q$, and ask the decision algorithm about the new samples; show that they are LWE samples if $g = s_1$ and uniform otherwise. How many calls to the decision algorithm does recovering all of $s$ take at most, for $n = 256$ and $q = 3329$?

23. ★ A naive hash-and-sign scheme signs a target $t$ with a secret basis $B$ by Babai rounding, so that $t - \sigma = xB$ with $x$ uniform in $[-\frac12, \frac12)^2$. For the basis rows $b_1 = (4, 1)$ and $b_2 = (-1, 3)$, compute the covariance matrix $E[(xB)^\mathsf{T}(xB)]$ of these differences. Explain what an attacker learns from many signatures, which scheme fell to this attack, and why [GPV](/gpv-signature/) and [Falcon](/falcon/) sample from a discrete Gaussian instead.

24. ★ Write a program that lists the supersingular $j$-invariants for a prime $p \equiv 3 \pmod 4$. One way: find the roots in $\mathbb{F}_{p^2}$ of $H_p(\lambda) = \sum_{i=0}^{m} \binom{m}{i}^2 \lambda^i$ with $m = (p-1)/2$, and map each root to $j = 2^8 (\lambda^2 - \lambda + 1)^3 / (\lambda^2 (\lambda - 1)^2)$. Check your program on $p = 431$ against the counts in [the supersingular isogeny problem](/supersingular-isogeny-problem/), then give the counts for $p = 419$, in total and in $\mathbb{F}_p$.
