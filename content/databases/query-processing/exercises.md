1. ◦ Relation $R$ has $M = 1000$ pages and $S$ has $N = 400$ pages, and there are $B = 52$ buffer pages. Count the page I/Os, without writing the output, of the page-at-a-time [nested-loop join](/nested-loop-join/) and of the [block nested-loop join](/block-nested-loop-join/), each with either relation as the outer one. Then decide whether the [Grace hash join](/grace-hash-join/) with $f = 1$, building on $S$, and the combined plan of the [sort-merge join](/sort-merge-join/) run in $3(M + N)$ here, and whether an in-memory [hash join](/hash-join/) is possible.

2. ◦ A [Bloom join](/bloom-join/) puts the $n = 1000$ distinct keys of $S$ into a filter of $m = 8000$ bits with $k = 4$ hash functions. $R$ has 100,000 tuples, of which 2000 have a partner in $S$, and its other keys are chosen independently of the hash functions. Estimate the false positive rate and the number of tuples of $R$ sent to the site of $S$.

3. ◦ [Hash aggregation](/hash-aggregation/) with room for $m = 2$ groups reads the records $(a, 4)$, $(b, 2)$, $(c, 6)$, $(a, 1)$, $(d, 3)$, $(b, 5)$, $(c, 2)$ and computes COUNT, SUM and AVG per key. Which records are spilled, what does level 0 output, and what does level 1 output if all its groups fit?

4. ◦ A fact table has the rows $(a_1, b_1, c_1)$, $(a_1, b_2, c_1)$, $(a_2, b_1, c_2)$, $(a_3, b_3, c_1)$ and $(a_4, b_1, c_2)$ on the dimensions $A$, $B$ and $C$. Compute the two upper bounds on the number of cells of its [data cube](/data-cube/), $\prod_i (C_i + 1)$ with $C_i$ distinct values per dimension and $1 + (2^D - 1)n$, and the actual number of cells of CUBE$(A, B, C)$ and of ROLLUP$(A, B, C)$. Then sort COUNT, MAX, AVG, the variance, MEDIAN and COUNT DISTINCT into distributive, algebraic and holistic aggregates.

5. ◦ A plan sorts on $a$ the result of a [hash aggregation](/hash-aggregation/) $\gamma_{a;\,\text{SUM}(b)}$ over a hash join $\sigma_p(R) \bowtie S$ that builds its table on $S$. Following [pipelining and materialization](/pipelining-and-materialization/), list the pipelines of the plan in the order they run and name the operator that ends each one. If instead the output of the selection (300 pages) and of the join (500 pages) were each written to disk and read back, how many extra page I/Os would that cost?

6. ◦ In [vectorized query execution](/vectorized-query-execution/), a batch holds the column vectors $x = [7, 2, 9, 4, 1, 8, 3, 6]$ and $y = [5, 1, 6, 8, 2, 0, 7, 4]$, positions numbered from 0. The query is SUM$(y)$ WHERE $x < 5$ AND $y > 1$, with one selection primitive per condition and a selection vector passed between them. Give the selection vector after each primitive, the sum, and the number of values each of the three primitives reads. Which vectors are copied?

7. ◦ Run the [Yannakakis algorithm](/yannakakis-algorithm/) on the path $R(A, B)$, $S(B, C)$, $T(C, D)$, $U(D, E)$ with the root $R$, for $R = \{(1,1), (2,2), (3,2), (4,9)\}$, $S = \{(1,3), (2,4), (2,5)\}$, $T = \{(3,6), (4,7), (5,6)\}$ and $U = \{(6,8), (9,9)\}$. Which tuples does each [semijoin](/semijoin/) pass remove, and what is the output? How many intermediate tuples does the plan $((R \bowtie S) \bowtie T) \bowtie U$ build on the original relations?

8. ◦ Run the leapfrog join of [leapfrog triejoin](/leapfrog-triejoin/) on the sorted lists $A = \{1, 3, 4, 7, 10, 12, 15\}$, $B = \{2, 4, 6, 10, 15, 20\}$ and $C = \{4, 5, 10, 11, 15\}$. List the moves, count them, and compare the count with the bound $m(n_{\min} + 1)$ of the entry.

9. ◦ The XML document is $r(a_1(b_1, c_1), a_2(a_3(c_2), b_2))$, with children in document order. Give each element its region code (start, end, level), numbering starts and ends with one counter from 0 in a depth-first walk and giving $r$ level 0. Find all matches of the twig $a[.//b]//c$. Which $a$ element does the [holistic twig join](/holistic-twig-join/) never push on its stack, and which path solutions does it output? How many pairs does a binary structural join for $a//c$ produce, and how many of them belong to no match?

10. ◦ Two lists grade six objects, and the score is the sum of the two grades: $a = (1.0, 0.7)$, $b = (0.9, 0.1)$, $c = (0.1, 1.0)$, $d = (0.2, 0.9)$, $e = (0.3, 0.8)$, $f = (0.4, 0.75)$. For $k = 1$, at what depth does the [threshold algorithm](/threshold-algorithm/) stop, and at what depth does [Fagin's algorithm](/fagin-algorithm/) stop? What do both return, and how many sorted and random accesses does the threshold algorithm make?

11. ◦ Points $(x, y)$, both to be minimized, are $a = (1, 9)$, $b = (2, 7)$, $c = (3, 8)$, $d = (4, 4)$, $e = (5, 5)$, $f = (6, 2)$, $g = (7, 3)$, $h = (8, 1)$, $i = (9, 6)$. Find the skyline. Sort the points by $x + y$, ties by the tuple, and run the [sort-filter skyline](/sort-filter-skyline/) with a window of $w = 2$. In which order and in which passes are the skyline points output?

12. ◦ The points $a = (1, 8)$, $b = (2, 6)$, $c = (3, 3)$, $d = (6, 2)$, $e = (8, 1)$, $f = (5, 6)$, $g = (7, 7)$, $h = (4, 9)$ and $i = (9, 4)$, both coordinates to be minimized, sit in an R-tree whose root has three leaves $L_1 = \{a, b, h\}$, $L_2 = \{c, d, e\}$ and $L_3 = \{f, g, i\}$. 15. • A [radix hash join](/radix-hash-join/) joins two inputs of $2^{26}$ tuples each. 16. • A relation of $N = 10{,}000$ pages is grouped by [sort-based aggregation](/sort-based-aggregation/). 17. • Run [BUC](/bottom-up-cube/) with minsup $= 2$ and COUNT on the rows $(x, p, 1)$, $(x, p, 2)$, $(x, q, 1)$, $(y, p, 1)$, $(y, q, 2)$, $(z, p, 1)$. 18. • An [exchange operator](/exchange-operator/) hash-partitions $10^6$ rows on the group key to 8 consumers, each of which aggregates its share. Now let each of the 8 producers aggregate locally first, as in two-phase aggregation, with 1000 groups in all. 19. • The plan is $\gamma_{T.g;\,\text{COUNT}(*)}((\sigma_{R.x < 10}(R) \bowtie_{R.k = S.k} S) \bowtie_{S.j = T.j} T)$ with hash tables built on $S$ and $T$. 23. • A [rank join](/rank-join/) with the sum as score and $k = 1$ joins $L = (a, 10), (b, 5), (c, 4), (d, 3)$ and $R = (e, 9), (b, 8), (f, 7), (g, 6), (c, 1)$, each pair a join key and a score, sorted by score.
