1. Mark the row player's best reply in each column (T against L, M against C, B against R) and the column player's best reply in each row (L against T, C against M, L against B). The cells marked twice are (T, L) and (M, C). In (B, R) the column player would switch to L, which pays 2 instead of 1.

2. With pure strategies the row player guarantees $\max_i \min_j M_{ij} = -1$ and the column player holds the row player to $\min_j \max_i M_{ij} = 3$, so there is no saddle point. The value is $v = 1$, with $x^* = (1/2, 1/2)$ and $y^* = (2/5, 3/5)$: $x^{*\mathsf T} M = (1, 1)$ and $M y^* = (1, 1)$.

3. (a) $\varepsilon = 1/5$. Against a fair coin the row player gets 0 whatever it does. The column player gets 0 now and $1/5$ by always showing tails. (b) $\varepsilon = 6/25$. The row player gets $-1/25$ now and $1/5$ by always showing tails, a gain of $6/25$; the column player gets $1/25$ now and $1/5$ by always showing tails, a gain of $4/25$.

4. At the fifty-fifty profile each player gets $3/4$; the row player gains $1/4$ by row 1 and nothing by row 2, and the column player gains $1/4$ by column 2. So $T$ gives the row player $(3/5, 2/5)$ and the column player $(2/5, 3/5)$. At (row 1, column 2) both players get 0 and each gains 1 by switching, so $T$ gives both players $(1/2, 1/2)$. Neither profile is fixed, so neither is an equilibrium.

6. Moving the weight of a dominated strategy to the strategy that dominates it raises the player's payoff strictly, so a profile that puts weight on it is not an equilibrium. In the game, L is dominated by C; then M by T; then R by C; then T by B. Only (B, C) is left, with payoffs $(4, 4)$, and any equilibrium of the original game uses only strategies that survive.

7. $M = \begin{pmatrix} 0 & -1 & 2 \\ 1 & 0 & -1 \\ -2 & 1 & 0 \end{pmatrix}$ is skew-symmetric, so the value is 0. A strategy $x$ guarantees 0 when $x_2 - 2x_3 \ge 0$, $x_3 - x_1 \ge 0$ and $2x_1 - x_2 \ge 0$. Adding twice the second inequality to the other two gives $0 \ge 0$, so all three hold with equality, and $x = (1/4, 1/2, 1/4)$ is the only optimal strategy.

9. Let $\alpha_j = a_{1j} - a_{2j}$ and $\beta_i = b_{i1} - b_{i2}$. If $\alpha_1$ and $\alpha_2$ have the same sign, the row player has a strictly dominant row, which it plays in every equilibrium (Exercise 6), and the column player has a unique best reply to it: one equilibrium. The same holds if $\beta_1$ and $\beta_2$ have the same sign. Otherwise a player who mixes must be indifferent, which pins the other player to one interior mix, so there is exactly one equilibrium that is not pure, the fully mixed one. Say $\alpha_1 > 0 > \alpha_2$. Then (1, 1) and (2, 2) are both equilibria if $\beta_1 > 0 > \beta_2$, and no pure cell is one if $\beta_1 < 0 < \beta_2$: three or one in all.

10. Take an equilibrium with supports $I$ and $J$. The set of pairs $(x, y)$ of mixed strategies with supports inside $I$ and $J$ in which every row of $I$ is a best reply to $y$ and every column of $J$ is a best reply to $x$ is a polytope described by linear inequalities with rational coefficients, and every point of it is an equilibrium. It is nonempty and bounded, so it has a vertex, and a vertex solves a system of linear equations with rational coefficients.
