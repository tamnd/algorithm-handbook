23. Count the pairs of a face and a corner in two ways. A quad mesh has $4F = 2E$, so $V - E + F = V - F$ and $\sum_v \operatorname{val} v = 2E = 4F$. That gives $\sum_v (4 - \operatorname{val} v) = 4V - 4F = 4\chi$. For triangles, $3F = 2E$ gives $6\chi$ in the same way. For genus 0 the sum is 8, and each term is at most 1, so at least 8 vertices have valence 3; the cube reaches this. For triangles the sum is 12, and each term is at most 3, so at least 4 vertices have valence below 6; the tetrahedron reaches this.

24. On quads $\sum_f n_f = 4F = 2E$, so $F' = 4F$ and $E' = 2E + 4F = 8F = 2F'$, and the mesh stays a quad mesh. The step keeps the topology, so $V_k = \chi + E_k - F_k = \chi + 4^k F$. For the valences: a vertex point keeps the valence of its old vertex, an edge point always has valence 4, and a face point has valence $n_f$. After the first step every face is a quad, so no new extraordinary vertices appear. On the tetrahedron this gives $4 + 4 = 8$.

25. Write $K$ for a binomial variable with parameters $n$ and $x$, so that $B_n(x^3) = E[(K/n)^3]$. Use $K^3 = K(K - 1)(K - 2) + 3K(K - 1) + K$ and $E[K(K - 1) \cdots (K - j + 1)] = n(n - 1) \cdots (n - j + 1)\, x^j$. Then $B_n(x^3) = [n(n - 1)(n - 2)x^3 + 3n(n - 1)x^2 + nx]/n^3$, which expands to the formula. The error is $3x^2(1 - x)/n + O(1/n^2)$, of order $1/n$. This agrees with Voronovskaya's limit $\tfrac12 f''(x)\, x(1 - x)/n$ for $f'' = 6x$.

27. The error is $x^2 + y^2 + z^2 + \tfrac13 (x + y + z - 3)^2$. Setting the gradient to zero gives $(I + \tfrac13 J)v = (1, 1, 1)$, where $J$ is the all-ones matrix, so $v = (\tfrac12, \tfrac12, \tfrac12)$, with the cost $\tfrac34 + \tfrac34 = \tfrac32$. With only $x = 0$ and $y = 0$ the matrix is $\operatorname{diag}(1, 1, 0)$, which is singular. Every point of the $z$ axis has cost 0, so the method falls back to the best of the two endpoints and their midpoint.
