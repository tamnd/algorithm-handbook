1. ◦ The graph has the vertices 0 to 8 and the edges $\{0,1\}$, $\{0,2\}$, $\{0,3\}$, $\{1,4\}$, $\{2,4\}$, $\{2,5\}$, $\{3,5\}$, $\{4,6\}$, $\{5,6\}$, $\{5,7\}$, $\{6,8\}$, $\{7,8\}$. Give the frontier of each round, the number of levels $D$, the edge slots read in each round and in total, and the vertices that are claimed by more than one frontier vertex in the same round. How many edge checks does the dense version with an array of flags make, if it scans every edge in each round?

2. ◦ In [frontier-based processing](/frontier-based-processing/), label propagation gives each vertex its own name as a label, and in each round the frontier vertices offer their labels to their neighbours, which keep the least; the next frontier is the set of vertices whose label changed, and the first frontier is all of $V$. Run it on the path $0, 1, 2, 3, 4, 5$. Count the rounds, including the last one, which changes nothing, and the edge slots read, and compare with the dense form, which reads all $2m$ slots in every round.

3. ◦ Run [Luby's algorithm](/luby-mis/) on the graph of Exercise 1 with the round-1 priorities $r = (4, 7, 1, 8, 3, 6, 0, 2, 5)$ for the vertices 0 to 8. Which vertices join in round 1, which are removed, and what happens in round 2? Give the independent set and the number of rounds.

4. ◦ Run [Jones-Plassmann](/jones-plassmann/) on the graph of Exercise 1 with $\rho = (2, 6, 8, 0, 5, 3, 7, 1, 4)$ for the vertices 0 to 8, with colours $0, 1, 2, \ldots$. Give the initial counters $wait(v)$, the ready set and the colours of each round, and the number of rounds. Find a longest path along which $\rho$ decreases, and check that the colouring is the greedy colouring in decreasing order of $\rho$.

5. ◦ The graph has the vertices 0 to 5 and the weighted edges $\{0,1\}$: 3, $\{1,2\}$: 8, $\{2,3\}$: 5, $\{3,4\}$: 9, $\{4,5\}$: 2, $\{5,0\}$: 6, $\{1,4\}$: 4, $\{0,3\}$: 7. Is it a [maximum weight matching](/maximum-weight-matching/)?

6. ◦ The graph has the vertices 0 to 7 and the weighted edges $\{0,1\}$: 6, $\{1,2\}$: 3, $\{2,3\}$: 7, $\{3,0\}$: 2, $\{4,5\}$: 5, $\{5,6\}$: 1, $\{6,7\}$: 8, $\{7,4\}$: 4, $\{1,5\}$: 9, $\{2,6\}$: 10. 7. ◦ In [Shiloach-Vishkin](/shiloach-vishkin/), a tree of the parent array is a chain: the root has height 0, and the vertex at height $h$ points to the vertex at height $h - 1$, up to height 20. Each shortcut sets $P[v] \leftarrow P[P[v]]$ for all $v$ at once. Give the height of the tree after each shortcut, with no hooking in between, and the number of shortcuts until it is a star.

8. ◦ [Ullman-Yannakakis](/ullman-yannakakis/) runs on a graph with $n = 10^6$ vertices, with $t = 1000$ and $c = 4$. Find the sampling probability $p$, the expected sample size, the number of squarings $\lceil \lg s \rceil$ when $s$ equals its mean, and the bound on the probability that the output is not exact.
