23. Andersen's analysis is sound, so it contains the precise answer. For the converse, $a \in pts(p)$ holds exactly when there are a statement `u = &a` and a path of copy edges $u = v_0 \to v_1 \to \cdots \to v_k = p$, one edge for each `v_{i+1} = v_i`. Take a shortest such path, so its variables are distinct. Run `u = &a` and then the copies along the path. Each copy writes only its left side, so when `v_{i+1} = v_i` runs, $v_i$ still holds $a$. After the last one, $p$ holds $a$.

Key idea: node variables are written only by statements `u = &v`, so any partial map $\sigma$ with each $\sigma(u)$ chosen among the targets of the statements of $u$ is reached by running each chosen statement once. The certificate is $\sigma$, of $O(n \log n)$ bits. The check follows $k + 1$ steps of $\sigma$ from $s$ and compares the end with $t$, in polynomial time. With the NP-hardness proof the restricted problem is NP-complete. A statement `*u = &v` writes to a location that depends on the current state, so not every combination of choices is reachable, and a run that reaches one may have to be long. For the general problem only membership in PSPACE is known.

25. Key idea: instantiate each ref node. A load `y = *a` gives an edge $x \to y$, and a store `*a = y` an edge $y \to x$, for each $x \in pts(a)$; do the same with some $z_c \in pts(c)$ for each other ref node $*c$ on the cycle, which exists because those sets are not empty. All these edges are constraints of Andersen's system once the least solution is reached, and they form a cycle through $x$ and $b$. Around a cycle of subset constraints every solution has equal sets, so the least solution has $pts(x) = pts(b)$. Merging $x$ and $b$ adds the constraint $pts(x) = pts(b)$, which the least solution already meets; the new system has fewer solutions and contains the old least one, so its least solution is the same.

26. Key idea: describe the answer without an order. A state is a partition of the locations and a partial target map from classes to classes. Call it closed if `p = &a` makes the class of $a$ the target of the class of $p$; `p = q` makes the target of $q$, if it has one, also the target of $p$; `p = *q` and `*p = q` impose the same rule one level down. Show by induction over the run that each merge and each target the algorithm sets holds in every closed state, so it is forced. The pending lists make the final state closed: a copy whose right side gets a target later is handled when it does. So the final state is the finest closed state, which is unique, and the sets do not depend on the order.

27. Key idea: split the variables by how $b_s$ treats them. Each $b_s$ maps a global to itself, so the global part of $GMOD(p)$ is the union of $IMOD^+(q) \cap Gl$ over the procedures $q$ reachable from $p$ in the call graph, which is the same for all of a strongly connected component. A formal $f$ of $q$ is in $GMOD(q)$ exactly when $q$ modifies it or passes it at some site to a formal in the GMOD set of the callee, which is the path condition of $RMOD$ in the binding graph. A local of $p$ enters only through $IMOD(p)$ or as an actual bound to a modified formal, which is $IMOD^+(p)$. Show that these sets satisfy the equation and, by induction on path length, that every solution contains them. Formals cannot be pushed over components because $b_s$ renames them, maps them to locals, or drops them when the actual is an expression, so a union over a component would mix names of different procedures.
