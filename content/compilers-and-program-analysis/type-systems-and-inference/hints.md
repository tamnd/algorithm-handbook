22. Unfold $P$: $P <: Q$ needs $P \to \mathsf{int} <: Q \to \mathsf{int}$ in field $f$, so $Q <: P$, and $Q$ has no field $x$. So $P \not<: Q$, and $Q \not<: P$ for the same missing field. $P' <: Q'$ holds: assume it, unfold both sides, drop $x$ by width, and the field $\mathit{next}$ asks for $P' <: Q'$ again, which the assumption gives. A field in which the type refers to itself in argument position turns width subtyping around, so an object with a method that takes another object of its own type does not become a subtype by adding fields.

23. Suppose $f$ gets the scheme $\forall\vec\alpha.\ \tau$. The body is an abstraction, so $\tau = \alpha' \to \tau'$, and $\tau'$ is the type of the use of `f`, an instance $S\tau$ of the scheme. Then $|\tau| = 1 + |\alpha'| + |S\tau| \geq 2 + |\tau|$, since a substitution never makes a type smaller. This is impossible. With equi-recursive types, $f : \forall\alpha.\ \mu\beta.\ \alpha \to \beta$, which unfolds to $\alpha \to (\mu\beta.\ \alpha \to \beta)$.
