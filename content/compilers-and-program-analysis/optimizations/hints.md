Show that the classes are the intervals $a_i + \cdots + a_j$, and that the class of an interval of length $L$ ends with one e-node for each of its $L - 1$ split points, since rotations reach every bracketing. That gives $n(n+1)/2$ classes and $n + \sum_{L=2}^{n} (n - L + 1)(L - 1) = n + \binom{n+1}{3}$ e-nodes. The root represents the Catalan number $C_{n-1}$ of bracketings. For $n = 4$: 10 classes, 14 e-nodes and 5 terms. A naive e-graph run confirms the counts for $n = 2$ to $6$.

22. $\pi \propto 2^{-c}$ gives $(1/2, 1/8, 1/4)$, normalized $(4/7, 1/7, 2/7)$ for the cheap instruction, the costly one and the unused slot. The proposal does not depend on the current state, so check detailed balance for $\nu \propto q\pi$: $\nu(x)\,q(y)\min(1, \pi(y)/\pi(x))$ is a constant times $q(x)\,q(y)\min(\pi(x), \pi(y))$, which is symmetric. With $q = (1/4, 1/4, 1/2)$ this gives $(4/9, 1/9, 4/9)$, so the unused slot gets far more than its share. A run of 200000 steps with seed 1 visits the three states with frequencies $0.445$, $0.111$ and $0.443$.

23. For the first part, take a site $(1, 2)$ and a site $(B, B)$ with budget $B$: greedy takes the small one first, the big one no longer fits, and it gets 2 out of $B$. For the second, stop greedy at the first site $k$ that does not fit. The sites taken so far plus all of $k$ have at least the benefit of the [fractional knapsack](/fractional-knapsack/) optimum, which bounds the 0-1 optimum. The sites taken before $k$ are part of the greedy choice, and $k$ fits alone, so the greedy benefit plus the best single benefit is at least the optimum, and the larger of the two is at least half. In 5000 random instances (seed 11) the ratio never fell below 0.62.

24. To semi-decide, run the program on all inputs in parallel, giving step $s$ to input $x$ in a dovetailed order, and accept when the instruction runs. To show that it is not decidable, put the instruction after code that simulates a machine on its input, as in the proof of the theorem. A set whose complement is also semi-decidable is decidable, so the never-executed instructions cannot even be listed. Every dead code pass therefore misses some unreachable code.
