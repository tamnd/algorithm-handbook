22. By induction on the program, every program computes a polynomial with nonnegative integer coefficients that is not zero, and every such polynomial is a sum of products of $x$ and $1$. If $p(1) = 1$, the coefficients sum to 1, so $p = x^j$ for some $j$, and $2^j \ne 3$. An enumeration by size never stops, because no size bound can certify that no larger program fits.

23. A differing input is a certificate of size linear in the inputs, checked by running both programs, so inequivalence is in NP. For hardness, compile a CNF formula $\varphi$ into a loop-free program with bitwise operations and compare it with the program that returns 0: they are equivalent exactly when $\varphi$ is unsatisfiable. Undecidability needs loops or unbounded data.

24. The program `if h = 0 then l := 0 else l := 1` is not noninterfering. Each of its traces, taken alone, is also a trace of `l := 0` or of `l := 1`, which are secure. A trace property true of both constant programs must contain all these traces, so it also holds of the insecure program. Noninterference compares two traces at a time, which makes it a hyperproperty.

25. The bounded checker reports no counterexample at any bound, and that proves only that the first $k$ steps avoid 7. The property "$x$ is even and $x \ne 7$" is preserved by $x := x + 2$ and holds at 0, so it is 1-inductive.

26. Step a can raise $y$ without bound, so any $p x + q y$ that decreases on step a for every $y'$ needs $q = 0$, and step b then needs $q \ge 1$. The relation $T_1 = \{x > 0 \wedge x' < x\}$ union $T_2 = \{y > 0 \wedge x' = x \wedge y' < y\}$ contains the transitive closure: a sequence of steps that contains step a lowers $x$, and a sequence of b steps keeps $x$ and lowers $y$. The pair $(x, y)$ in lexicographic order decreases on both steps.
