1. ◦ A function with integer inputs `x` and `y` sets `z = x - y` if `x > y` and `z = y - x` otherwise, and then fails if `z == 3`. Write the [path condition](/path-condition/) of each of its four paths in the symbols $\alpha$ and $\beta$ for `x` and `y`, and count how many inputs in $[0, 5]^2$ follow each path.

2. ◦ Compute the [strongest postcondition](/strongest-postcondition/) of `y := x + 1; x := 2 * y` from $x \ge 0$, with the assignment rule $\mathrm{sp}(x := e, P) = \exists x_0.\ P[x_0/x] \wedge x = e[x_0/x]$. Then compute it with the wrong rule $P \wedge x = e$ and say what goes wrong. Finally, for `x := 0` with $P_1 = (x = 1)$ and $P_2 = (x = 2)$, compare $\mathrm{sp}(S, P_1 \wedge P_2)$ with $\mathrm{sp}(S, P_1) \wedge \mathrm{sp}(S, P_2)$.

3. ◦ For `x := 0; while x < 5 do x := x + 2`, started from $\mathit{true}$, compute the set of states at the loop head as the least fixed point of $X \mapsto (x = 0) \vee \mathrm{sp}(x := x + 2, X \wedge x < 5)$, and give the strongest postcondition of the whole program.

4. ◦ A program on one integer input `x` runs three tests in sequence: `if x > 0 then A`, `if x > 5 then B`, `if x > 10 then C`, where A, B and C do not change `x`. How many paths does its control flow graph have from entry to exit? How many leaves and how many forks (nodes with two feasible children) does its [symbolic execution tree](/symbolic-execution-tree/) have?

5. ◦ A loop-free function is `if p then (if q then A else B) else C; if r then D; if s then (if t then E else F; if u then G)`. Count its paths from entry to exit by the dynamic program over the acyclic control flow graph, and say how many symbolic states remain at the exit when every join merges its states, as in the [path explosion problem](/path-explosion-problem/).

6. ◦ Run depth-first [concolic testing](/concolic-testing/) on `if x > 10 then (if y == x + 3 then error)`, starting from the input $(0, 0)$, with an exact solver. List the runs and the path condition that each solver call solves. How many runs and how many successful solver calls are made, and does the answer depend on the model the solver returns?

7. ◦ A [coverage-guided fuzzer](/coverage-guided-fuzzing/) puts hit counts into the buckets 1, 2, 3, 4–7, 8–15, 16–31, 32–127 and 128 or more. So far its map has seen edge $e_1$ only in the bucket 4–7 and edge $e_2$ only in the bucket 16–31. Run 1 hits $e_1$ five times and $e_2$ twelve times; then run 2 hits $e_1$ seven times and $e_2$ twenty times. Which runs does it keep?

8. ◦ The program `i := 0; s := 0; while i < n do (s := s + 2*i + 1; i := i + 1)` has precondition $n \ge 0$, postcondition $s = n^2$ and loop invariant $s = i^2 \wedge i \le n$. Write the three verification conditions that [verification condition generation](/verification-condition-generation/) produces and check that each is valid. Which one fails if the invariant is only $s = i^2$? Give a state that shows it.

9. ◦ The grammar $E \to x \mid y \mid 1 \mid E + E \mid E \times E$ defines the search space of a [program synthesis](/program-synthesis/) problem. Count its programs with 1, 3, 5 and 7 nodes. Does any program of this grammar compute $\max(x, y)$ on all integers?

10. ◦ The input is $r$ and the output is $g$. For each LTL formula, say whether it is realizable by a Mealy machine, and whether by a Moore machine, in the sense of [reactive synthesis](/reactive-synthesis/): (a) $\mathbf{G}(r \rightarrow \mathbf{X}\, g) \wedge \mathbf{G}(g \rightarrow r)$; (b) $\mathbf{G}(r \rightarrow \mathbf{F}\, g) \wedge \mathbf{G}(g \rightarrow r)$; (c) $\mathbf{G}\mathbf{F}\, r \rightarrow \mathbf{G}\mathbf{F}\, g$; (d) $\mathbf{G}\mathbf{F}\, g \wedge \mathbf{G}(g \rightarrow r)$. Which of them are satisfiable but not realizable?

11. • Concolic testers replace a nonlinear subterm by its value in the current run. Run depth-first concolic testing on `if (y * y) % 50 == x then (if x > 30 then error)` from $(0, 0)$, with a solver that keeps every input not named in its formula at its last value. List the runs and solver calls, and say whether the error is found. Give an input that reaches it.

12. • Run [delta debugging](/delta-debugging/) (ddmin, with subsets tried before complements, in order) on the list $0, 1, \ldots, 7$, where a test fails exactly when the list contains 5. Count the tests. Then show that for $N = 2^k$ elements, of which only the element at index $i$ (counting from 0) causes the failure, ddmin makes exactly $k + w(i)$ tests, where $w(i)$ is the number of 1 bits of $i$.

13. • The loop `x := 0; y := 0; while * do (x := x + 1; y := y + 2)` has the candidate invariants $x \ge 0$, $y \ge 0$, $y = 2x$, $x \le y$, $x \le 10$ and $y = x$. Run the [Houdini algorithm](/houdini-algorithm/). Which candidates are removed, in which call, and how many prover calls are made in all? Does the answer depend on the counterexamples the prover returns?

14. • A loop starts at $x = 0, y = 0$ and repeats one of two steps for ever: $(x, y) := (x + 1, y)$ or $(x, y) := (x + 1, y + 1)$. Use the [Farkas method](/farkas-invariant-generation/) to find an inductive inequality $c \cdot (x, y) + d \le 0$ that excludes the point $(0, 1)$: give $c$ and $d$, the multipliers for initiation, and for each step the multipliers of a consecution certificate with $\mu = 1$.

15. • For the loop `while x >= 1 and y >= 1 do x := x - y` (with $y$ unchanged), write the six rows $A x + A' x' \le b$ of its relation, and give multipliers $\lambda_1$ and $\lambda_2$ that satisfy the linear program of [linear ranking function synthesis](/ranking-function-synthesis/). Which ranking function, bound and decrease do they give? How many turns does the loop make from $(10, 3)$, and what bound does the ranking function give? What happens without the guard $y \ge 1$?

16. • Take $l$ low and $h$ high. For each program say whether it is [noninterfering](/noninterference/) (termination-insensitive, as defined in Volume 45), whether a flow-insensitive security type system accepts it (one that rejects any assignment to $l$ of an expression that mentions $h$ and any assignment to $l$ under a condition on $h$, and allows a loop on $h$ whose body assigns only high variables), and whether a flow-sensitive analysis that tracks the level of $h$ after each assignment accepts it. (a) `l := h mod 2`; (b) `if h > 0 then l := 1 else l := 1`; (c) `h := l; l := h + 1`; (d) `while h > 0 do h := h - 1; l := l + 1`.

17. • A compiler applies strength reduction to the source `i := 0; s := 0; while i < n do (s := s + 4*i; i := i + 1)` and produces the target `i := 0; s := 0; j := 0; while i < n do (s := s + j; j := j + 4; i := i + 1)`, with output $s$. For [translation validation](/translation-validation/) with cut points at the entries, loop heads and exits, give the relation at the loop heads and check the entry, step and exit conditions.

18. • Expressions are $e ::= n \mid x \mid e + e \mid e \times e \mid e / e$, where division by zero goes wrong. A folding pass replaces an operator whose operands fold to numerals by its value when it does not divide by zero, and rewrites $0 \times e$ to $0$. Prove by structural induction that $[\![\mathrm{fold}\, e]\!]\rho = [\![e]\!]\rho$ whenever $[\![e]\!]\rho$ does not go wrong. Is the rule $0 \times e \to 0$ correct in the sense of [verified compilation](/verified-compilation/), $\mathrm{Beh}(T) \subseteq \mathrm{Beh}(S)$ when $S$ cannot go wrong? Would the reverse rule $0 \to 0 \times (1 / x)$ be correct?

19. • Run [bottom-up enumerative synthesis](/bottom-up-enumerative-synthesis/) for the grammar $E \to x \mid 1 \mid E + E \mid E \times E$ on the examples $1 \mapsto 2$, $2 \mapsto 5$, $3 \mapsto 10$, with observational equivalence. How many programs of size 3 are built, and how many new vectors are kept? At which size is the first consistent program found, and which program is it?

20. • A sketch on 4-bit unsigned integers is `(x + ??1) & ??2`, and it must equal `x ^ 8` (exclusive or) for every `x`. Run [CEGIS](/cegis/) as in [program sketching](/program-sketching/), starting from the candidate $(0, 0)$, with a verifier that returns the least counterexample and a solver that returns the least pair $(??_1, ??_2)$ in lexicographic order that fits all counterexamples so far. List the candidates and counterexamples. How many completions are correct?

21. • For [type-directed synthesis](/type-directed-synthesis/) of a function of type int → int from the examples $0 \mapsto 1$, $1 \mapsto 2$, $2 \mapsto 4$, $3 \mapsto 8$: are the examples trace complete? Below the guard $x < 1$, the step worlds are $x = 1, 2, 3$, where the call $f\ (x - 1)$ reads 1, 2 and 4 from the examples. E-terms are built from $x$, $0$ and $1$ (size 1 each), the call $f\ (x - 1)$ (size 2) and the operators $+$, $-$ and $\times$ (size 1 each). Show that no E-term of size at most 4 gives the outputs $(2, 4, 8)$, and give one of size 5 and the resulting program.

22. ★ Show that the programs of the grammar $E \to x \mid 1 \mid E + E \mid E \times E$, over one integer input $x$, compute exactly the nonzero polynomials in $x$ with nonnegative integer coefficients. Conclude that the examples $1 \mapsto 1$ and $2 \mapsto 3$ have no consistent program, and say what an enumeration by size does on them.

23. ★ Two loop-free programs over fixed-width bit vectors, with the same inputs and one output, are equivalent when they give the same output on every input. Show that deciding equivalence is coNP-complete. Why does this not contradict the undecidability of program equivalence?

24. ★ View a deterministic program as the set of its traces, the pairs (start state, final state), over variables $l$ and $h$. A trace property is a set $T$ of traces, and a program has it when all its traces lie in $T$. Show that no trace property holds of exactly the noninterfering programs, using `if h = 0 then l := 0 else l := 1`.

25. ★ The program `x := 0; loop for ever: x := x + 2` must keep $x \ne 7$. What does [bounded model checking](/bounded-model-checking/) report at bound $k$, and what does that prove? Show that $x \ne 7$ is not $k$-inductive for any $k$ in the sense of [k-induction](/k-induction/), and give a stronger property that is 1-inductive.

26. ★ An integer loop runs while $x > 0 \wedge y > 0$, and each turn does one of two steps: $(x, y) := (x - 1, y')$ for any integer $y'$, or $(x, y) := (x, y - 1)$. Show that no linear function $p x + q y$ decreases by at least 1 on every turn, find a disjunctively well-founded [transition invariant](/transition-invariants/) with two parts, and give a lexicographic ranking function.
