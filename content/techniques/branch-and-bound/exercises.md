1. ◦ A knapsack has capacity 15 and five items, already sorted by value per unit of weight: values 36, 50, 28, 30, 10 and weights 3, 5, 4, 6, 5. At the root, compute (a) the sum of all values, (b) the capacity times the largest ratio of value to weight, (c) the [fractional knapsack](/fractional-knapsack/) bound, and (d) the value of the greedy packing that takes each item in order when it still fits. Which of the four are valid upper bounds on the optimum, and which valid one is the tightest?

2. ◦ A minimization integer program has integer objective coefficients, so every feasible value is an integer. The incumbent is 20. The nodes below are taken in this order, and each line gives what the linear program at the node returns: A, infeasible; B, value 22; C, value 18 at an integral point; D, value 19.5; E, value 17.2; F, value 16.6. For each node, say whether the [fathoming rule](/fathoming-rule/) drops it and by which test, or whether it must be branched, and give the incumbent after it.

3. ◦ A search tree is a full ternary tree of depth 10, and the bound never prunes. [Depth-first branch and bound](/depth-first-branch-and-bound/) pushes all children of a node when it expands it, and [breadth-first branch and bound](/breadth-first-branch-and-bound/) appends them to its queue. What is the largest number of nodes on the stack at one time? On the queue?

4. ◦ Four cities have arc costs as follows: the entry in row $i$ and column $j$ is the cost of the arc from $i$ to $j$, and the rows are (–, 8, 12, 5), (7, –, 4, 9), (10, 6, –, 3) and (6, 11, 7, –). Reduce the rows and then the columns as in [Little's algorithm](/little-algorithm/), and give the bound at the root. Then show that the tour $1 \to 2 \to 3 \to 4 \to 1$ is optimal without any branching.

5. ◦ A branching algorithm whose two children have sizes $n - a$ and $n - b$ makes $O(\tau^n)$ leaves, where $\tau$ is the positive root of $x^{-a} + x^{-b} = 1$. Compute $\tau$ to four decimal places for the branching vectors $(1, 2)$, $(1, 3)$, $(2, 2)$, $(2, 3)$ and $(1, 5)$. In [branch and reduce](/branch-and-reduce/) for maximum independent set, branching on which vertices gives the vector $(1, 5)$? Why do $(2, 3)$ and $(1, 5)$ give the same number?

6. ◦ Let $f(x) = x^2 - 2x$ on $X = [0, 3]$. Evaluate the natural interval extension, in which $X^2 = [0, 9]$ and $2X = [0, 6]$ are computed separately, and compare it with the true range of $f$ on $X$. Then evaluate the same function written as $(x - 1)^2 - 1$, with the square of an interval computed exactly. Which form gives [interval branch and bound](/interval-branch-and-bound/) the better bound?

7. ◦ Three facilities go to three locations on a line at positions 0, 1 and 2, so the distances are $d_{12} = d_{23} = 1$ and $d_{13} = 2$. The flows are $f_{12} = 5$, $f_{13} = 2$ and $f_{23} = 3$, both matrices are symmetric with zero diagonal, and a placement $\pi$ costs $\sum_{i \ne j} f_{ij} d_{\pi(i)\pi(j)}$. Compute the $3 \times 3$ matrix of minimum scalar products used by the [Gilmore-Lawler bound](/gilmore-lawler-bound/), the bound itself, and the optimum.

8. ◦ Maximize $5x_1 + 8x_2$ subject to $2x_1 + x_2 \le 12$, $x_1 + 6x_2 \le 38$, $x_1, x_2 \ge 0$ and integer. Solve the linear program at the root of the [Land-Doig algorithm](/land-doig-algorithm/), branch on $x_1$, and solve the linear programs of the two children. What does the search know after these three linear programs?

9. • Run depth-first branch and bound on the knapsack of Exercise 1 with the fractional bound. Decide the items in order, try the child that takes the item first, set the incumbent at every node to the value of the items taken when that is larger, and drop a node when its bound is at most the incumbent. List the nodes in the order they are visited, mark which are expanded, and give the sequence of incumbent values and the optimal packing.

10. • On the same instance, with the incumbent updated when a node is made and a node dropped when it is taken out with a bound at most the incumbent, count the nodes expanded by [best-first branch and bound](/best-first-branch-and-bound/) and by breadth-first branch and bound. Which node does breadth-first expand that the other two orders do not, and why? Show that no branch and bound search with this bound can expand fewer nodes than best-first does here.

11. • Finish the Land-Doig search of Exercise 8: take the live node with the largest value of the linear program, branch on the fractional variable with the smallest index, and count the linear programs solved. Compare the optimum with the root solution rounded down and with the root solution rounded to the nearest integer point.

12. • In a knapsack with items sorted by ratio, let $c$ be the first item that does not fit when the items are taken in order. Prove that the fractional bound $U$ at the root satisfies $U < \mathrm{OPT} + v_c$. Deduce that if every item fits alone in the knapsack, the larger of the greedy prefix and the single item $c$ has value at least $\mathrm{OPT}/2$. Check both claims on the instance of Exercise 1.

13. • Apply [dominance pruning](/dominance-pruning/) to the knapsack of Exercise 1: at each level keep a pair (weight, value) only if no other pair has weight at most and value at least as large, keeping one copy of equal pairs. How many pairs survive at each of the five levels, and how many nodes are kept in all, against the number of feasible nodes of the full tree? Prove that with integer weights no level keeps more than $W + 1$ pairs.

14. • A solver stops early by dropping every node whose bound $u$ satisfies $u \le (1 + \varepsilon) z$, where $z > 0$ is the incumbent of a maximization problem. Prove that the solution it returns has value at least $\mathrm{OPT}/(1 + \varepsilon)$. Run the depth-first search of Exercise 9 with $\varepsilon = 0.1$: which value does it return, and how many nodes does it expand?

15. • Give a family of search trees with valid bounds, one for each $k \ge 1$, on which depth-first branch and bound with a fixed child order and no starting incumbent expands $\Theta(2^k)$ nodes, while best-first branch and bound expands $O(k)$.

16. • A 0-1 program has the constraints $3x_1 - 2x_2 + x_3 + 2x_4 - x_5 \ge 2$ and $-x_1 + 4x_2 - 3x_3 + x_4 + 2x_5 \ge 3$. In the [Balas additive algorithm](/balas-additive-algorithm/) a node is dropped when some row cannot be satisfied even if every free variable with a positive coefficient is set to 1. Apply this test at node A, where $x_1 = x_4 = 0$, and at node B, where $x_2 = 0$ and $x_5 = 1$. At B the test passes; show that the second row forces three of the free variables, and that the node is infeasible after all.

17. • In maximum independent set, (a) prove that if $v$ has exactly one neighbour, some maximum independent set contains $v$. (b) Show that the degree 0 and degree 1 rules alone find $\alpha(P_7) = 4$ for a path on seven vertices. (c) On a cycle of seven vertices no such rule applies. Branch on one vertex and finish each child with the rules; what is $\alpha(C_7)$?

18. • Which of these are valid [branching rules](/branching-rule/), in the sense that the children cover the parent and each makes progress? (a) For binary $x_j$: $x_j = 0$ or $x_j = 1$. (b) For binary $x_1, x_2$: $x_1 + x_2 \le 0$ or $x_1 + x_2 \ge 2$. (c) For binary $x_1, x_2$: three children $x_1 = 0$; $x_1 = 1, x_2 = 0$; $x_1 = 1, x_2 = 1$. (d) For an integer $x_3$ whose value in the linear program is exactly 2: $x_3 \le 2$ or $x_3 \ge 3$. (e) For a tour problem: the arc $(i, j)$ is in the tour, or it is not.

19. ★ Best-first order expands few nodes but needs memory; depth-first order needs little memory. For a maximization problem with integer values and integer bounds at most $U$, consider this loop: for $t = U, U - 1, \ldots$ run a depth-first search that expands a node only when its bound is at least $t$ and stops at the first feasible solution of value at least $t$. Prove that the first run that succeeds has $t = z^*$ and returns an optimal solution. Bound the total number of expansions in terms of $U - z^*$ and the number $K$ of nodes whose bound and whose ancestors' bounds are all at least $z^*$. How can the next threshold be chosen to make fewer runs?

20. ★ Prove that the bound of the reduced cost matrix in Little's algorithm is never larger than the optimum of the assignment problem on the same matrix, with the diagonal forbidden. Compute both for the three cities with $c_{12} = 4$, $c_{13} = 9$, $c_{21} = 3$, $c_{23} = 6$, $c_{31} = 8$, $c_{32} = 2$, and show that for three cities the assignment bound always equals the best tour.

21. ★ For $f(x) = x^2 - 2x$ and the box $X = [1 - r, 1 + r]$ with $0 < r \le 1$, compute the natural interval extension of Exercise 6 and the true range of $f$. Show that the excess width is $8r - r^2$, so the error of the lower bound shrinks only linearly with the width of the box. How small must $r$ be for the lower bound to be within $0.01$ of the true minimum? What does this mean for the number of boxes that interval branch and bound keeps near a minimizer?

22. ★ Prove that starting depth-first branch and bound with a larger initial incumbent never makes it expand a node that it would not expand with a smaller one, when the child order is fixed and nodes are dropped when their bound is at most the incumbent. Then explain, using Exercise 10, why on the instance of Exercise 1 even the initial incumbent 116 leaves seven nodes to expand.
