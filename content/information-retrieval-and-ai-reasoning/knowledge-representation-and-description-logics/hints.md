1. $\exists r.A \sqcap \forall r.(A \sqcup B)$ is $\{1, 2\}$: element 1 has the successor 2 in $A$ and both successors in $A \cup B$, and 2 has the successor 4. $\forall r.\bot$ is $\{3, 4\}$, the elements without successors. $\exists r.\exists r.A$ is $\{1\}$, through $1 \to 2 \to 4$.

3. With $A$ read as $p$ and $B$ as $q$, the first concept is $\Box(p \vee \Diamond\neg q)$. The formula is $\exists r.\forall r.A \sqcap \forall r.\exists r.\neg A$. It is unsatisfiable: the $r$-successor that the first conjunct asks for has all its successors in $A$, and the second conjunct asks it for a successor outside $A$.

6. Brute force tests every ordered pair of distinct names, $7 \cdot 6 = 42$ tests. Each $B_i$ has one subsumer and each $C_j$ has two, so 10 tests succeed. The direct hierarchy is the tree itself, with 6 edges.

8. At $t = 1$, $\neg\mathit{HoldsAt}(\mathit{Open}, 1)$, from $\mathit{InitiallyN}$. At $t = 4$ the door is open, at $t = 7$ it is closed, and at $t = 12$ it is open, each from the last event before $t$ and the absence of a later opposite event before $t$. Without $\mathit{InitiallyN}(\mathit{Open})$, neither literal follows at $t = 1$: no event before 1 settles the value.

9. The and-nodes have disjoint variables, the inner or-node splits on $x_2$ and the top one on $x_1$, so it is a d-DNNF. Without smoothing the pass gives $1 + 1 = 2$ for the inner or-node, 2 for the left branch, 1 for the right, and 3 in total. Smoothing multiplies the child $x_2$ by $(x_3 \vee \neg x_3)$ and the branch $\neg x_1 \wedge x_3$ by $(x_2 \vee \neg x_2)$, which gives $3 + 2 = 5$. The right count is 5: three models with $x_1$ true ($x_2 \vee x_3$) and two with $x_1$ false ($x_3$, any $x_2$).

11. The root gets $A$, $\neg B$ and $\exists r.B$; its child gets $B$ and $\exists r.C$; the grandchild gets $C$ and $\exists r.A$. The next child would start from $\{A\}$, which is contained in the root's label, so it is blocked after 3 expanded nodes. The disjointness axioms make the three elements pairwise different, so the smallest model is the 3-cycle $a \to b \to c \to a$. Without $C \sqsubseteq \neg A$ one element can be in $A$ and $C$: $a \in A \sqcap C$, $b \in B$ and $r = \{(a, b), (b, a), (a, a)\}$ is a model with 2 elements, and 1 element is impossible since $A \sqsubseteq \neg B$.

12. From $A \sqsubseteq \exists r.B$ the rules record the edge $(A, B)$ for $r$, and $C$ is a subsumer of $B$, so $\exists r.C \sqsubseteq D$ adds $D$ to the subsumers of $A$, and then $A \sqcap D \sqsubseteq E$ adds $E$. Now $E \sqsubseteq \exists s.A$ gives the edge $(A, A)$ for $s$, and since $E$ is a subsumer of $A$, $\exists s.E \sqsubseteq H$ adds $H$. The subsumers are $\{A, D, E, H, \top\}$ for $A$, $\{B, C, \top\}$ for $B$, $\{E, H, \top\}$ for $E$, and the name and $\top$ for $C$, $D$ and $H$. The direct hierarchy has $A \sqsubseteq D$, $A \sqsubseteq E$, $E \sqsubseteq H$ and $B \sqsubseteq C$.

15. Regress the goal and each precondition through the actions before it. $\mathit{Locked}(do(\mathit{lock}, s))$ regresses to $\mathit{true}$. $\mathit{Poss}(\mathit{open}, do(\mathit{unlock}, S_0))$ becomes $\neg(\mathit{Locked}(S_0) \wedge \mathit{unlock} \ne \mathit{unlock})$, which is $\mathit{true}$, and $\mathit{Poss}(\mathit{lock}, do(\mathit{close}, s))$ becomes $\neg\mathit{Open}(do(\mathit{close}, s))$, which is also $\mathit{true}$. So the plan works whatever the initial database says. For $\mathit{open}, \mathit{lock}$, the precondition of $\mathit{lock}$ regresses to $\neg\mathit{true}$, so that sequence is never executable.

17. The clauses split into $\{x_1 \vee x_2, x_2 \vee x_3\}$ and $\{x_4 \vee x_5\}$. The first branches on $x_2$ and gives $x_2 \vee (\neg x_2 \wedge x_1 \wedge x_3)$ after unit propagation; the second branches on $x_4$ and gives $x_4 \vee (\neg x_4 \wedge x_5)$. After smoothing, the counts are $4 + 1 = 5$ and $2 + 1 = 3$, and the root gives 15.

22. Use a binary counter. Take $\top \sqsubseteq \exists r.\top$, and for each bit $i$, with $L_i = X_1 \sqcap \cdots \sqcap X_{i-1}$ ($\top$ for $i = 1$): $L_i \sqcap X_i \sqsubseteq \forall r.\neg X_i$, $L_i \sqcap \neg X_i \sqsubseteq \forall r.X_i$, $\neg L_i \sqcap X_i \sqsubseteq \forall r.X_i$ and $\neg L_i \sqcap \neg X_i \sqsubseteq \forall r.\neg X_i$. The successors of an element with value $k$ have value $k + 1 \bmod 2^n$, so an $r$-path from $\mathit{Zero}$ meets $2^n$ different values; a $2^n$-cycle is a model. A label that contains another node's starting set has the same bits, so the first blocked node is at depth $2^n$, where the value is 0 again and the root blocks it.

23. Each node at depth $i < n$ has two successors, so the run creates $2^{n+1} - 1$ nodes. Depth first, it keeps only the current path, $n + 1$ nodes. The smallest model has 2 elements: $p$ in every $A_i$ and $q$ in none, with $r$ the full relation on $\{p, q\}$, and $C_n$ true at $p$. One element cannot have successors inside and outside $A_1$.

24. In the canonical model, an assertion $A(a)$ or $r(a, b)$ starts an infinite $r$-chain, since every element in $A$ has a successor and every successor is in $A$. With neither kind of assertion, $A$ and $r$ can be empty. So $q_k$ is entailed for every $k \ge 1$ exactly when the ABox has some $A$ or some $r$ assertion, and $\exists x.\, A(x) \vee \exists x \exists y.\, r(x, y)$ is a rewriting of all of them. PerfectRef reaches it by reducing the last atom to $r(x_{k-1}, \_)$, rewriting it to $A(x_{k-1})$, then back to $r(x_{k-2}, \_)$, and so on.

25. On a right-linear vtree every prime is a literal, and the SDD is the reduced OBDD for the order $x_1, \ldots, x_k, y_1, \ldots, y_k$, with two elements per decision node and the last node a literal. The $x_j$ level has one node per subset $S \subseteq \{1, \ldots, j - 1\}$ of true $x$'s, $2^k - 1$ in all. After all the $x$'s are read, the function is $\bigvee_{i \in S} y_i$, and the $y_j$ level has a node for each $S \subseteq \{j, \ldots, k\}$ that contains $j$ and has at least two elements, since a single $y_j$ is a literal. That gives $2^k - 1 - k$ more nodes, and twice the total number of nodes is $2^{k+2} - 2k - 4$.

26. After $\mathit{unlock}$ the strongest statement about $S_1$ is $\neg\mathit{Locked}(S_1)$. $\mathit{Open}(S_1)$ equals $\mathit{Open}(S_0)$, which is unknown, because the disjunct that held in $S_0$ may have been $\mathit{Locked}(S_0)$. After $\mathit{close}$ it is $\neg\mathit{Open}(S_2) \wedge \neg\mathit{Locked}(S_2)$. In this propositional case, progression conjoins the old database with the effect equations and forgets the old values. Forgetting (FO) is polynomial on DNNF, DNF, PI and MODS.
